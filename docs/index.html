C++20 Zero-Heap Industrial IoT Framework

Deterministic, High-Performance Embedded IoT

AetherIoT is an ultra-reliable, zero-heap C++20 bare-metal framework designed for industrial telemetry, smart agriculture, hydroponics dosing, weather stations, and high-density multi-actuator systems across all Espressif silicon.

5-Line Declarative Quickstart

Get up and running in seconds with automatic Wi-Fi failover, real-time web telemetry, and safety range guards.

main.cpp 
#include "iot_framework.hpp"

IOT_APP(app) {
    // 1. Declarative Safety Guard
    iot::guard("Temperature").max(35.0f).on_breach([](auto, auto v) {
        iot::log_error("ALERT: Temperature %.1f C exceeded safe limit!", v);
    });

    // 2. Real-Time Telemetry Stream
    app.on_data([](auto d) {
        iot::log_info("Temp: %.1f C | Humidity: %.1f %%RH | pH: %.2f", d.temp, d.hum, d.ph);
    });
}

Actuators & Multi-Servo Matrix

High-density multi-servo controller with relay-like declarative syntax (open, close, toggle), 16-channel relays, PCA9685 12-bit PWM, and 74HC595 shift registers.

Multi-Servo Relay-Like Usage 
// 1. Assign descriptive names to servo channels
iot::servo_name(0, "MainPipeValve");
iot::servo_name(1, "InletValveA");

// 2. Calibrate Closed (0 deg) and Open (90 deg) angles
iot::servo_set_calib(0, 0.0f, 90.0f);

// 3. Declarative relay-style operations
iot::servo_open("MainPipeValve");   // Opens servo to 90 deg
iot::servo_close("InletValveA");    // Closes servo to 0 deg
iot::servo_toggle(0);               // Inverts current state
bool open = iot::servo_is_open(0);  // Query state

High-Density Sensor Multiplexing

TCA9548A 8-channel I2C MUX, 1-Wire DS18B20 multi-drop array (16 probes on 1 pin), and CD74HC4067 16-channel analog MUX.

Multiplexing Example 
// 1. Read 1-Wire multi-drop temperature array (16 probes on 1 GPIO)
float temp_zone1 = iot::read_temp_probe(0);
float temp_zone2 = iot::read_temp_probe(1);

// 2. Read 16-channel analog multiplexer (CD74HC4067)
float analog_v0 = iot::read_analog_mux_voltage(0);

// 3. Switch I2C Channel via TCA9548A (Channel 0 to 7)
iot::i2c_channel(0);
float lux = iot::read_lux();

Decoupled Encryption & Anti-Replay

Independent symmetric ciphers (AES-256-CBC, AES-128, ChaCha20, HMAC) paired with an orthogonal anti-replay validation layer.

Security Configuration 
// 1. Select independent symmetric cipher
iot::set_encryption(iot::Security::AES_256_CBC, "SecretKey256BitPanjang32Karakter!");

// 2. Enable/disable decoupled anti-replay protection
iot::enable_anti_replay(true, 60); // 60-second tolerance window

Custom Extensible CLI Engine

Easily register custom commands with fluent chaining, typed arguments (int, float, bool), rich responses, and auto-generated help menus.

Custom CLI Registration 
// Register custom command with typed arguments
iot::cli("pump")
    .description("Control industrial process pump")
    .usage("pump  [volume_ml]")
    .on_execute([](auto& ctx) {
        auto action = ctx.arg(0);
        float volume = ctx.arg_float(1, 10.0f);

        if (action == "dose") {
            iot::dose_ml(iot::Relay::PUMP_MAIN, volume);
            ctx.respond_ok("Dosed %.1f mL successfully.", volume);
        } else if (action == "on") {
            iot::on(iot::Relay::PUMP_MAIN);
            ctx.respond_ok("Pump turned ON.");
        } else {
            iot::off(iot::Relay::PUMP_MAIN);
            ctx.respond_ok("Pump turned OFF.");
        }
    });

Custom Dynamic Multi-Page LCD

Fully user-defined LCD multi-page flipper with dynamic telemetry callbacks, custom labels, and direct cursor printing.

Custom LCD Configuration 
// 1. Define custom dynamic multi-page LCD layouts
iot::lcd_page("Main Page")
    .line(0, "== FARM NODE #1 ==")
    .line(1, [](auto& d, auto& out) { out.format("Temp: %.1fC", d.temp); })
    .line(2, [](auto& d, auto& out) { out.format("pH: %.2f EC: %.0f", d.ph, d.ec); })
    .line(3, [](auto& d, auto& out) { out.format("Status: %s", d.online ? "ONLINE" : "STANDBY"); });

// 2. Define secondary power monitoring page
iot::lcd_page("Power")
    .line(0, "== POWER STATS ==")
    .line(1, [](auto& d, auto& out) { out.format("V: %.1fV I: %.2fA", d.voltage, d.current); })
    .line(2, [](auto& d, auto& out) { out.format("Bat: %u%%", d.battery_pct); });

// 3. Or print directly to any row/col:
iot::lcd_print(0, 0, "Emergency Stop!");

Configurable CSV Profiles & SD Logging

Pre-configured industry CSV presets (Environmental, Energy, Water, Agri, Vibration) with zero-data-loss SD logging and custom formatters.

CSV Logging Profiles & Custom Formatters 
// 1. Choose from pre-configured industry profiles:
iot::csv_preset(iot::CSVProfile::ENVIRONMENTAL);     // Temp, Hum, Pres, Lux, PM2.5, Rain
iot::csv_preset(iot::CSVProfile::ELECTRICAL_ENERGY); // AC Volts, Amps, Power, Energy kWh
iot::csv_preset(iot::CSVProfile::WATER_AQUACULTURE); // WaterTemp, pH, EC, TDS, DO, Salinity
iot::csv_preset(iot::CSVProfile::VIBRATION_STRUCTURAL); // Pitch, Roll, Vibration, Health

// 2. Or provide custom header and formatting callback:
iot::csv_custom_header("timestamp,temp,pressure,flow_rate\n");
iot::csv_custom_formatter([](const auto& d, uint32_t ts, auto& out) {
    out.format("%lu,%.2f,%.1f,%.2f\n", ts, d.temp, d.pressure, d.flow_rate);
});

Customizable MQTT Broker & Topic Schema

Fluent MQTT configuration supporting custom brokers, auth credentials, custom pub/sub topic trees, QoS 0-2, retain, and JSON serializers.

Fluent MQTT Configuration 
// Configure custom MQTT broker and topic tree with fluent chaining:
iot::mqtt()
    .broker("mqtt.enterprise.io", 8883)
    .credentials("gate_01", "operator", "SecretPass123")
    .telemetry_topic("factory/line1/telemetry")
    .command_topic("factory/line1/control")
    .qos(1)
    .retain(true);

Modbus RTU / RS-485 Master Engine

Decoupled Modbus query builder with standard function codes (FC01-FC16), deterministic CRC-16, and response dispatchers.

Modbus Query & Response Chaining 
// Query slave device holding registers with fluent callbacks:
iot::modbus_query(1)
    .read_holding(0x0001, 2)
    .on_response([](uint8_t slave, auto fc, std::span regs) {
        printf("Received from slave %u: Reg0=%u, Reg1=%u\n", slave, regs[0], regs[1]);
    })
    .execute();

Debounced Hardware Buttons & Long-Press

Fluent digital inputs with active low/high polarity, internal pullups, and chained press, release, and long-press event handlers.

Button Chaining & Long-Press Detection 
// Register button on GPIO 0 with debounce and long-press handler:
iot::button(0, true)
    .on_press([]() { printf("Tactile button pressed!\n"); })
    .on_long_press(3000, []() {
        printf("Emergency Factory Reset Triggered!\n");
    });
